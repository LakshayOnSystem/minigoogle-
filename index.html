PageRank Formula (Brin & Page, 1998) d = 0.85

PR(u) = (1 - d)/N + d · Σ [ PR(v) / outDegree(v) ]

Each outgoing link from page v passes an equal share of v’s authority to target page u. Pages with zero incoming links receive only the base teleportation score: (1 - 0.85) / 6 = 0.025 (2.5%).
